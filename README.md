# 11/11 限定版媽媽

送給媽媽的生日網頁影片。點「打開禮物」開始播放，許願那一幕點一下畫面就能吹熄蠟燭，最後是全家福。

**觀看：** https://coolalxeanderyi.github.io/Birthday/

![11/11 限定版媽媽](assets/og.jpg)

## 怎麼看

- 手機、平板、電腦都能開，記得打開聲音
- 手機轉成橫向，畫面會更大
- 許願時點一下畫面吹熄蠟燭，16 秒沒點也會自動吹熄
- 看完可以按「再看一次」

## 怎麼做的

整支影片就是一個 `index.html`。每一格畫面都用 Canvas 2D 即時畫出來，時間軸跟著 Web Audio 的音樂時鐘走，所以畫面和音樂不會跑掉。沒有用任何框架或函式庫。

- **公仔場景**：AI 生成（FLUX.2 Klein），用 Real-ESRGAN 放大，再用 IS-Net 把公仔和背景切開分層，最後統一調成暖色
- **鏡頭與動作**：每一幕有推拉和平移，前後景分層移動做出景深；公仔用定格動畫的方式跳動、探頭、推蛋糕
- **互動**：許願那段音樂會一直循環，等媽媽點畫面才接下一段
- **配樂**：用 GeneralUser GS 音色庫重新編曲的〈生日快樂〉，旋律為公共版權
- **字型**：jf open 粉圓、芫荽、Pacifico，只留下用到的字

## 檔案

| 路徑 | 內容 |
